## 🧰 Setup (VS Code)

> Getting your machine ready to run C++ 👇

| Step | What to do |
|------|------------|
| 1️⃣ | Install a compiler → [MinGW-w64](https://www.mingw-w64.org/) (Windows) or use pre-installed `g++` (Linux/Mac) |
| 2️⃣ | Install [VS Code](https://code.visualstudio.com/) |
| 3️⃣ | Add the **C/C++** extension by Microsoft |
| 4️⃣ | Open the folder in VS Code — you're all set! ✅ |

---

## ▶️ How to Run

```bash
g++ filename.cpp -o output
./output
```
